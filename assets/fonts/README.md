# 鲸鱼娘中文字体

用户对照实际字幕、画面中文与片尾后，选择站酷快乐体（ZCOOL KuaiLe）。中文使用该字体的 Regular 原始字形，中文行中的拉丁字母沿用原片 Shantell Sans。

- 原始项目：https://github.com/googlefonts/zcool-kuaile
- 下载地址：https://raw.githubusercontent.com/googlefonts/zcool-kuaile/main/fonts/ttf/ZCOOLKuaiLe-Regular.ttf
- 取得日期：2026-09-27。
- 字体 SHA-256：812a6fc1fe54b6d73a419245c32dfeba8aa33104d5be90d1cf6af082007cb71d。
- 发布包采用 SIL Open Font License 1.1，完整许可随附 ZCOOLKuaiLe-OFL.txt。这里没有修改字体字形或将其重新命名发布。

本地字体由 src/whale-fonts.js 加载并等待完成，之后才开始绘帧；字体文件计入渲染指纹，不需要安装到操作系统。
